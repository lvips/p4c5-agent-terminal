# R4 修复验证报告：ALDO4 万用表实测

> **版本**：v1.0（2026-09-06，CCA T18）
> **目的**：验证 commit `2b7cedf`（ALDO4 2.9V → 3.4V）在硬件上的实际输出
> **状态**： 待实测（本文档为测量指南，数据由用户填入）

---

## 1. 背景

**M12 修复**：`p4c5_pmic.cc` 中 ALDO4 电压从 2.9V 改为 3.4V。

| 项 | 理论值 | 来源 |
|---|---|---|
| ML307C 最低工作电压 | **3.4V** | ML307C 规格书 p.11 |
| ML307C 典型工作电压 | 3.8V | ML307C 规格书 p.11 |
| AXP2101 ALDO4 范围 | 0.5V – 3.5V | AXP2101 规格书 p.54 §6.13.2.80 |
| ALDO4 寄存器 0x95 | N=29 → 3.4V | 公式 V = 0.5 + N×0.1 |
| **代码配置** | **3.4V (3.4f)** | p4c5_pmic.cc L308 |

**串口已确认**：
```
I (1290) p4c5_pmic:   ALDO4 = 3.4V ✅ (R4 fixed: was 2.9V, ML307C needs ≥3.4V)
```
但这是代码打印的值，需要万用表实测 PMIC 实际输出电压。

---

## 2. 测量点（3 选 1）

根据原理图 `硬件开源资料/ESP32P4C5开发板 酷世DIY/硬件原理图/原理图.pdf`，ALDO4 供电路径为：

```
AXP2101 ALDO4 引脚 → 滤波电容(C) → 4G电源控制(MOSFET, GPIO4 控制) → ML307C VBAT
```

| 选项 | 位置 | 难度 | 推荐度 |
|---|---|---|---|
| **A: 4G电源控制输出 pad** | 4G电源控制 section 输出端 | ⭐⭐ 中等 | ⭐⭐⭐ 最推荐 |
| B: ML307C VBAT pin | 模组本体 | ⭐⭐⭐ 较难 | ⭐⭐ 需放大镜 |
| C: AXP2101 ALDO4 滤波电容 | PMIC section 附近 | ⭐⭐ 中等 | ⭐⭐ 含 MOSFET 压降 |

### 推荐：选项 A

在原理图右下角 **4G电源控制** section，找到 MOSFET 漏极输出 pad（通常在 MOSFET 和 ML307C 之间，靠近模组）。此处电压 = 实际到达 ML307C 的 VBAT。

**识别方法**：
1. 看 4G电源控制 section（原理图右下角区域）
2. 找到 MOSFET（N-MOS 或 P-MOS，受 GPIO4 控制）
3. MOSFET 输出端 → 一个 10uF 滤波电容 → 到 ML307C
4. 测电容正极或 MOSFET 输出 pad

### 备选：选项 B

直接在 ML307C 模组上测。参考 `docs/hw/datasheets/ml307c/` 中引脚定义。注意：LCC/LGA 封装引脚密集，需要放大镜 + 尖细探针。

### 备选：选项 C

在 AXP2101 PMIC 芯片附近找到 ALDO4 输出的滤波电容（通常标号类似 C_ALDO4 或 C_LDO4）。注意：此点测的是 PMIC 直接输出，包含后续 MOSFET 压降差异。

## 3. 万用表设置

| 设置项 | 值 |
|---|---|
| **模式** | DC 电压 |
| **量程** | 20V 档（或自动量程） |
| **黑表笔** | 板子 GND（大铜皮、USB 外壳、或 GND 过孔） |
| **红表笔** | 上述测量点 |

---

## 4. 测量步骤

1. **断电**：拔掉 USB，断开电池（如有）
2. **准备万用表**：调到 DC 20V 档，检查表笔接触良好
3. **黑表笔固定**：夹到板子 GND（大铜皮或 GND 过孔）
4. **红表笔定位**：对准测量点，但不要接触
5. **通电**：插 USB 线（不要开串口工具，纯供电即可）
6. **等待 10 秒**：让 PMIC 初始化完成（ALDO4 在 app_main 步骤 [1/5] 才设置）
7. **接触测量点**：红表笔轻轻点测量点，保持稳定 3-5 秒
8. **读数**：记录稳定后的电压值（保留 2 位小数）
9. **断电**：先拔 USB，再取下表笔

---

## 5. 安全注意事项

- ️ **不要带电插拔表笔** — 可能短路到旁边焊盘
- ⚠️ **红表笔尖锐** — 不要划伤 PCB 或焊盘
- ⚠️ **不要同时接触两个点** — 短路可能烧毁 PMIC 或 ML307C
- ⚠️ **GPIO4 必须为高** — ALDO4 才能输出；如果刚上电还没跑代码，ALDO4 可能是 0V
  - 解决方法：上电后等 10 秒（app_main 会运行并设置 ALDO4=3.4V）
- ✅ **万用表内阻高（~10MΩ）** — 不会明显影响电路
- ✅ **测量时间 < 10 秒** — 避免长时间接触导致探针滑移

## 6. 预期结果

| 测量点 | 理论值 | 合格范围 | 说明 |
|---|---|---|---|
| ALDO4 (选项 A/C) | **3.40V** | **3.30V – 3.50V** | 包含 ±3% 调节精度 |
| ML307C VBAT (选项 B) | 3.35V – 3.40V | ≥ 3.30V | MOSFET 可能有 0-50mV 压降 |

**判断**：
- 读数 ≥ 3.30V → ✅ 修复有效，ML307C 可以工作
- 读数 2.8V – 3.3V → 🟡 不足，ML307C 可能无法启动 PA
- 读数 ≤ 2.9V → ❌ R4 修复未生效（代码/寄存器问题）
- 读数 = 0V → ❌ ALDO4 未使能（检查 GPIO4 或 LDO enable 寄存器）

## 附录

### A. 相关代码
- ALDO4 设置：`components/p4c5_pmic/p4c5_pmic.cc` 函数 `pmic_init()`
- 串口打印：`"ALDO4 = 3.4V ✅ (R4 fixed: was 2.9V, ML307C needs ≥3.4V)"`

### B. 寄存器参考
- ALDO4 电压寄存器：`REG95` (0x95)，bits[4:0]
- 公式：V = 0.5V + N×0.1V → 3.4V = N×0.1 + 0.5 → N=29 (0x1D)
- ALDO4 使能寄存器：`REG90` (0x90)，bit[3]

### C. ML307C 规格
- 供电：3.4V – 4.5V，Typ 3.8V
- 发射峰值电流：~500mA @ 23dBm
- 注意：ALDO4 最大 3.5V，无法达到 ML307C 典型值 3.8V
  - ML307C 内部有 DC-DC 降压，可在 3.4V 输入下工作
  - PA 发射时电压跌落需示波器进一步验证
