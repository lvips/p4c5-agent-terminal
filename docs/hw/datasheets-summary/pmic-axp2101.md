## 1. AXP2101 核心规格

| 项 | 规格 |
|---|---|
| **类型** | 高度集成的电源管理 IC（PMIC）|
| **I2C 地址** | **0x34** |
| **输入电压** | 2.6V - 5.5V（USB 5V 或锂电池 3.0-4.2V）|
| **封装** | 5×5 mm QFN-40 |
| **DCDC 输出** | DCDC1 (0.5-3.4V/100mV step) + DCDC2/3/4 (变频) + DCDC5 (1.4-3.7V/100mV step) |
| **LDO 输出** | ALDO1-4 (100mV-3.7V/100mV step) + BLDOx (0.5-1.4V/50mV step) |
| **充电** | 内置 CC/CV 充电管理（充电电流可配）|
| **库仑计** | 精确电量计量（±3%）|
| **温度保护** | 内置热保护 + 电池温度监测 |
| **GPIO** | 2 个多功能 GPIO（用作 IRQ / LDO 控制）|

### 输出通道清单（参考 xiaozhi 本项目使用）

| 通道 | 类型 | 范围 | **本项目配置** | 用途 |
|---|---|---|---|---|
| DCDC1 | 通用 DC-DC | 0.5-3.4V | **3.3V** | ESP32-P4 / C5 / 外设主电源 |
| DCDC2 | 通用 DC-DC | 0.5-1.2V 或 1.22-1.54V | 未用 | — |
| DCDC3 | 通用 DC-DC | 0.5-1.2V 或 1.22-1.54V 或 1.6-3.4V | 未用 | — |
| DCDC4 | 通用 DC-DC | 0.5-1.2V 或 1.22-1.84V | 未用 | — |
| DCDC5 | 通用 DC-DC | 1.4-3.7V | 未用 | — |
| **ALDO1** | 模拟 LDO | 100mV-3.7V | **1.8V** | 辅助（可能给 C5 内部）|
| ALDO2 | 模拟 LDO | 100mV-3.7V | 未用 | — |
| **ALDO3** | 模拟 LDO | 100mV-3.7V | **3.3V** | 音频 codec（ES8311 + ES7210）|
| **ALDO4** | 模拟 LDO | 100mV-3.7V | **2.9V** | 4G 模组 VBAT |
| BLDO0 | 低噪声 LDO | 0.5-1.4V | 未用 | — |
| BLDO1 | 低噪声 LDO | 0.5-1.4V | 未用 | — |

## 2. 本项目的电源配置（来自 xiaozhi）

从 `kevin_p4c5_4g_board.cc` 第 99-119 行确认：

```c
// AXP2101 初始化序列
axp2101_set_dcdc_voltage(KSDIY_PMIC_DCDC1, 3.3f);  // 主电源
axp2101_set_dcdc_enabled(KSDIY_PMIC_DCDC1, true);
axp2101_set_ldo_voltage(KSDIY_PMIC_LDO_ALDO1, 1.8f);
axp2101_set_ldo_enabled(KSDIY_PMIC_LDO_ALDO1, true);
axp2101_set_ldo_voltage(KSDIY_PMIC_LDO_ALDO3, 3.3f);  // 音频
axp2101_set_ldo_enabled(KSDIY_PMIC_LDO_ALDO3, true);
axp2101_set_ldo_voltage(KSDIY_PMIC_LDO_ALDO4, 2.9f);  // 4G VBAT
axp2101_set_ldo_enabled(KSDIY_PMIC_LDO_ALDO4, true);
vTaskDelay(pdMS_TO_TICKS(50));  // 等待 50ms 稳定
```

⚠️ **ALDO4 = 2.9V 与 ML307C 规格书（3.4-4.2V）冲突** — 已在 `ml307c.md` 标注，需要 M1 实机验证。

## 4. 充电与电量管理

| 流程 | 说明 |
|---|---|
| 涓流充电 | 电池 < 3V 时小电流（~50mA）预充 |
| 恒流充电 | 默认 500mA（可配，最高 1A）|
| 恒压充电 | 4.2V 截止 |
| 停止充电 | 充满后自动停止（带再充功能）|
| 温度保护 | 高温/低温停止充电 |

### 电量计算

```c
// xiaozhi API
charging = pmic_->IsCharging();      // 充电中？
discharging = pmic_->IsDischarging(); // 放电中？
level = pmic_->GetBatteryLevel();     // 电量百分比 0-100
```

- **库仑计法**：±3% 精度（vs OMT 的简单电压法 ±15%）
- 内部 ADC 监测 VBUS / VBAT / 电流 / 温度
- 充电状态实时可读

## 5. 与 OMT NP-F 电池方案的差异

| 维度 | OMT Tab5 | 新硬件 P4C5 |
|---|---|---|
| 充电 IC | 简单充电 IC | AXP2101 内置 |
| 电量检测 | ADC 电压法（±15%）| 库仑计（±3%）|
| 多路电源 | 无 | DCDC1+ALDO1-4 可控 |
| 4G VBAT | 始终上电 | 可通过 ALDO4 控制 |
| 充电电流 | 固定 | 可配（推荐 500mA）|
| 温度保护 | 简单阈值 | 多温度点监测 |
| **代码复杂度** | 低 | 中-高（需 14 寄存器配置）|

**优势**：电量精度大幅提升，4G 模组可独立断电节省电量。
**代价**：AXP2101 驱动代码更复杂（需要详细读规格书）。

## 7. 风险标注

| ID | 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|---|
| R4.1 | **14 个寄存器含义未逐一核对** | 100% | 高 | CCA 写驱动时**必须**双源对照 xiaozhi 代码 + AXP2101 规格书 |
| R4.2 | 充电电流典型值（500mA）未实测 | 100% | 低 | M1 阶段用万用表测 |
| R4.3 | 电池类型（锂电池 vs 锂聚合物）需确认 | 100% | 低 | 查电池丝印 |
| R4.4 | 库仑计需要完整充放电循环才能校准 | 100% | 中 | M1 阶段跑一次完整循环 |
| R4.5 | AXP2101 I2C 与 ES8311/ES7210/触摸/IMU 共线 | 0% | - | 地址不冲突（已在 audio-codecs.md 验证）|
| R4.6 | 温度保护阈值未在代码中读取 | 100% | 低 | M5 阶段做温度监控 |
| R4.7 | 库仑计与 OCV（开路电压）结合的电量算法 | 100% | 中 | 默认用 AXP2101 自带库仑计即可 |
