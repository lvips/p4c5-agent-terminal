## 1. ES8311（DAC - 扬声器输出）

| 项 | 规格 |
|---|---|
| **类型** | 低功耗单声道音频 DAC + 耳机放大器 |
| **I2C 地址** | **0x18** |
| **I2S 接口** | MCLK / BCLK / WS / SDIN/SDOUT |
| **采样率** | 8k / 11.025k / 16k / 22.05k / 24k / 32k / 44.1k / 48k |
| **位深** | 16/20/24/32 bit |
| **输出** | 32Ω 耳机（差分）或 16Ω（单端）|
| **工作电压** | AVDD 3.3V / DVDD 1.8V（共用 3.3V 通过 LDO）|
| **PA 接口** | 1 个单声道差分输出（可驱动外部 PA）|
| **关键寄存器** | 0x00 (STATE) / 0x01 (CLK) / 0x02 (DAC_CLK) / 0x32 (DAC_CTRL) |
| **PA 控制** | 内部 PA 可关闭，外接 NS4150B 时由 GPIO3 控制 |

### 关键寄存器清单

| 寄存器 | 名称 | 默认值 | 说明 |
|---|---|---|---|
| 0x00 | STATE | 0x00 | 复位 / 电源管理 |
| 0x01 | CLK | 0x00 | 时钟分频 / 模式选择 |
| 0x02 | DAC_CLK | 0x00 | DAC 时钟 |
| 0x06 | PWR | 0x00 | 电源管理（VMID/DAC/ADC）|
| 0x32 | DAC_CTRL | 0x00 | DAC 控制（音量 / 静音）|
| 0x37 | ADC_VOL | 0x00 | ADC 音量（本项目不用 ADC）|
| 0x45 | GPIO | 0x00 | GPIO 控制 |

### I2C 初始化序列（10 步，简化）

```
1. 写 0x00 = 0x80  // 软复位
2. 等待 10ms
3. 写 0x01 = 0x3F  // 时钟配置（24kHz MCLK=256fs）
4. 写 0x02 = 0x00  // DAC 时钟
5. 写 0x06 = 0x00  // 上电 DAC + VMID
6. 写 0x32 = 0xBF  // DAC 音量 + 静音解除
7. 写 0x45 = 0x00  // GPIO 不翻转
8. 写 0x0E = 0x02  // 启用 I2S 主模式
9. 写 0x12 = 0x00  // 数字静音解除
10. 等待 50ms
```

⚠️ **真实寄存器值以 xiaozhi 代码为准**：`kevin_p4c5_4g_board.cc` 用 `es8311_codec_new()` 封装，不需要手写寄存器。

## 2. ES7210（ADC - 麦克风输入）

| 项 | 规格 |
|---|---|
| **类型** | 4 通道高性能音频 ADC（24-bit）|
| **I2C 地址** | **0x40** |
| **I2S 接口** | MCLK / BCLK / WS / SDOUT |
| **采样率** | 8k - 96k Hz |
| **位深** | 24-bit |
| **4 mic 通道** | MIC1+/- / MIC2+/- / MIC3+/- / MIC4+/- |
| **工作电压** | 3.3V（共用 ALDO3）|
| **关键特性** | 内置麦克风前置放大器 + AEC 回声消除参考输入 |

⚠️ **规格书未在 docs/hw/datasheets/** — 需要补：

**补拷路径**（任选一）：
1. 从 xiaozhi 解压后的 `components/` 目录找
2. 从 Espressif 官网下载：`es7210_datasheet.pdf`
3. 从 OMT 仓库拷贝（OMT 也用 ES7210）

### I2C 初始化序列（参考 OMT，已稳定）

```
1. 写 0x00 = 0xFF  // 软复位
2. 等待 10ms
3. 写 0x01 = 0x00  // 时钟主模式
4. 写 0x06 = 0x00  // 启用 MIC1-4 + MICBIAS
5. 写 0x07 = 0x00  // 模拟电源管理
6. 写 0x08 = 0x00  // 数字电源管理
7. 写 0x09 = 0x00  // 数字音量
8. 等待 50ms
9. 写 0x00 = 0x41  // 解复位 + 上电
10. 等待 100ms
```

### 通道选择

| 寄存器 | 值 | 说明 |
|---|---|---|
| `es7210_cfg.mic_selected` | `ES7210_SEL_MIC1 \| ES7210_SEL_MIC2 \| ES7210_SEL_MIC3 \| ES7210_SEL_MIC4` | 4 麦全开 |
| AEC 参考 | `input_reference = true` | 启用 ES8311 DAC 输出作为 AEC 参考（回声消除）|

## 3. NS4150B（PA - 扬声器功放）

| 项 | 规格 |
|---|---|
| **类型** | D 类（Class-D）单声道音频功放 |
| **输出功率** | 3W @ 4Ω / 5V（典型 2.5W @ 8Ω / 5V）|
| **效率** | ~90%（D 类特性）|
| **输入电压** | 2.5V - 5.5V |
| **静态电流** | 2.5mA（典型）|
| **关断电流** | < 1µA |
| **THD+N** | 0.1% @ 1W / 8Ω / 1kHz |
| **控制引脚** | **EN**（高电平使能，本项目接 **GPIO3**）|
| **输出** | 直接驱动 4Ω / 8Ω 扬声器 |

### 应用电路

- 电源：5V（VBUS 或 BOOST_5V）
- 输入：ES8311 差分输出
- 输出：1× 扬声器（4Ω 或 8Ω）
- EN：GPIO3（拉高启用，拉低进入关断模式）

### 风险

- **未测**：5V 升压稳定性（BOOST_5V 来源待确认）
- **建议**：加散热（3W 输出有热）

## 4. MSM381A3729H9CP（MEMS 麦克风 ×4）

| 项 | 规格 |
|---|---|
| **类型** | MEMS 数字麦克风（PDM 输出）|
| **灵敏度** | -26 dBFS（94dB SPL @ 1kHz）|
| **信噪比** | ≥ 65 dBA |
| **THD** | < 1% @ 100dB SPL |
| **工作电压** | 1.5V - 3.6V（共用 ALDO3 = 3.3V）|
| **频响** | 50Hz - 20kHz |
| **封装** | 3.5×2.65×0.98 mm SMD |

### 4 个麦克风连接

| 麦 | 接到 ES7210 通道 |
|---|---|
| MIC1 (左前) | MIC1+ / MIC1- 差分 |
| MIC2 (右前) | MIC2+ / MIC2- 差分 |
| MIC3 (左后) | MIC3+ / MIC3- 差分 |
| MIC4 (右后) | MIC4+ / MIC4- 差分 |

## 5. I2C 总线地址冲突检查

| 设备 | 地址 | 是否冲突 |
|---|---|---|
| **ES8311** | 0x18 | ✅ 唯一 |
| **ES7210** | 0x40 | ✅ 唯一 |
| **AXP2101** | 0x34 | ✅ 唯一 |
| **ST7123 触摸** | 0x5A（默认）| ✅ 唯一（待 PDF 确认）|
| **LSM6DS3 IMU** | 0x6A（默认）| ✅ 唯一 |
| **MCP4725 DAC** | 0x60 | ✅ 唯一 |

✅ **所有 I2C 设备地址无冲突**，可共享 I2C0 总线（SDA=GPIO7, SCL=GPIO8）。

## 6. I2S 引脚配置

| 信号 | GPIO | 方向 | 用途 |
|---|---|---|---|
| **MCLK** | GPIO13 | OUT | 音频主时钟（24kHz × 256 = 6.144 MHz）|
| **BCLK** | GPIO12 | OUT | 音频位时钟 |
| **WS** | GPIO10 | OUT | 音频字选择 |
| **DOUT** | GPIO9 | OUT | DAC 数据（ESP → ES8311）|
| **DIN** | GPIO11 | IN | ADC 数据（ES7210 → ESP）|
| **PA_EN** | GPIO3 | OUT | NS4150B 使能 |
