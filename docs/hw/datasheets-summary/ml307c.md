## 1. 模组核心规格

| 项 | 规格 | 备注 |
|---|---|---|
| **型号** | ML307C-DC-CN | 中移 OneMO Cat.1 |
| **网络制式** | LTE-TDD / LTE-FDD Cat.1 + GSM（多频段）| 4G + 2G 回落 |
| **GNSS** | GPS + 北斗 | 同步支持 |
| **数据速率** | LTE Cat.1: 下行 10Mbps / 上行 5Mbps | 满足 DSH 通信 |
| **工作电压** | 3.4V - 4.2V（推荐 3.8V）| 本项目用 AXP2101 ALDO4 = 2.9V ❌ 不够 |
| **发射电流** | 峰值 ~500mA @ 23dBm | 高功耗 |
| **工作温度** | -30°C ~ +75°C | 工业级 |
| **封装** | LCC + LGA | 贴片 |
| **尺寸** | 约 24×24×2.5 mm | 小 |

⚠️ **关键风险**：硬件规格书标注 3.4-4.2V，但 xiaozhi 配置 ALDO4 = 2.9V。**可能是规格书误读或 2.9V 是待机电压、4G 发射时升压**。**M1 阶段必须实机验证**。

## 2. UART 通信协议

| 项 | 默认值 |
|---|---|
| 波特率 | 115200 bps（可改 9600/57600/230400/460800）|
| 数据位 | 8 |
| 校验位 | None |
| 停止位 | 1 |
| 流控 | RTS/CTS（默认关闭）|

### 关键 AT 指令（10 个）

| 指令 | 用途 | 文档来源 |
|---|---|---|
| `AT` | 测试连通性 | 总览 |
| `AT+CPIN?` | 查询 SIM 卡状态 | 总览 |
| `AT+CSQ` | 查询信号强度 | 总览 |
| `AT+CREG?` | 查询网络注册状态 | 总览 |
| `AT+CGDCONT=1,"IP","APN"` | 设置 APN 接入点 | 总览 |
| `AT+MIPCALL=1,1` | 发起 PDP 拨号（建立 IP 连接）| TCP/IP 用户手册 |
| `AT+MIPOPEN=1,0,"TCP",host,port` | 建立 TCP 连接 | TCP/IP 用户手册 |
| `AT+MIPSEND=1,len` | 发送数据 | TCP/IP 用户手册 |
| `AT+MQTTNEW=...` | 创建 MQTT 客户端 | MQTT 用户手册 |
| `AT+MQTTCON=...` | 连接 MQTT broker | MQTT 用户手册 |

### PPP 拨号流程（5 步）

参考 `ML307C_拨号上网用户手册_V1.0.1.pdf`：

```
1. AT+CPIN?                    # 确认 SIM 卡就绪
2. AT+CSQ                      # 确认信号正常
3. AT+CREG?                    # 确认注册到网络
4. AT+CGDCONT=1,"IP","CMNET"   # 设置 APN（中国移动）
5. AT+MIPCALL=1,1              # 发起拨号
```

返回 `+MIPCALL: 1,1,"10.168.x.x"` 表示拨号成功，获得 IP。

## 3. 引脚定义与硬件连接

### 关键引脚（来自原理图）

| 名称 | 方向 | 描述 |
|---|---|---|
| VBAT | 电源输入 | 3.4-4.2V（推荐 3.8V）|
| GND | - | 地 |
| PWRKEY | 输入 | 拉低 ≥ 100ms 开机 |
| RESET | 输入 | 拉低复位 |
| **TXD** | 输出（AT 响应）| UART TXD |
| **RXD** | 输入（AT 命令）| UART RXD |
| RTS | 输出 | 请求发送 |
| CTS | 输入 | 清除发送 |
| DTR | 输入 | 数据终端就绪（休眠控制）|
| USIM_VDD | 输出 | SIM 卡供电（1.8V / 3.0V）|
| USIM_DATA | I/O | SIM 卡数据 |
| USIM_CLK | 输出 | SIM 卡时钟 |
| USIM_RST | 输出 | SIM 卡复位 |
| USIM_DET | 输入 | SIM 卡在位检测（高 = 在位）|
| ANT | - | 主天线（IPEX 1 代）|
| GNSS_ANT | - | GNSS 天线（IPEX 1 代）|

### 本项目连接

| 模组引脚 | 接到 |
|---|---|
| VBAT | AXP2101 ALDO4（2.9V） ⚠️ 电压可能不足 |
| GND | GND |
| PWRKEY | GPIO4（高电平开机/拉低关机）|
| TXD | GPIO53（ESP32-P4 UART RX）|
| RXD | GPIO52（ESP32-P4 UART TX）|
| DTR | GPIO51（休眠控制）|
| USIM_* | Nano SIM 卡座 |

## 5. 与 OMT HU006 的差异

| 维度 | OMT HU006 | 新硬件 ML307C |
|---|---|---|
| **厂商** | 上海移远（Quectel）| 中移 OneMO |
| **Cat.1 速率** | 10/5 Mbps | 10/5 Mbps（相同）|
| **AT 指令** | Quectel 标准 | OneMO 扩展 AT |
| **MQTT 指令** | `AT+QMT*` | `AT+MQTT*` |
| **驱动** | `esp_modem` + `microlink` | `78/esp-ml307` v3.6.4 |
| **GNSS** | ❌ 无 | ✅ GPS + 北斗 |
| **封装** | LCC | LCC（类似）|
| **温度** | 工业级 | 工业级 |

**驱动迁移成本**：esp-ml307 比 microlink **更成熟**（已支持 SSL、HTTP、MQTT），代码量更少。

## 6. 风险标注

| ID | 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|---|
| R2.1 | **电压问题**：规格书 3.4-4.2V vs xiaozhi ALDO4 = 2.9V | 100% | 极高 | **M1 立即实机验证**：测 ML307C 实际供电电压 + 4G 拨号是否成功 |
| R2.2 | 4G 模组功耗高（Cat.1 发射 ~500mA）| 100% | 高 | AXP2101 ALDO4 控制上下电；M5 阶段做低功耗 |
| R2.3 | 网络延迟比 WiFi 慢 ~100ms | 100% | 低 | DSH 体验可接受（< 2s 网络延迟目标）|
| R2.4 | **流量费用** | 100% | 中 | **强烈建议用定向流量包**（避免天价账单）|
| R2.5 | 部分 AT 指令与 Quectel 签名不同 | 30% | 低 | esp-ml307 已封装，直接用高级 API |
| R2.6 | 网络注册时间（首次冷启动 ~30s）| 100% | 低 | 接受 |
| R2.7 | PPP 拨号稳定性（24h 长稳）| 50% | 中 | M1 阶段做 24h 长稳测试 |
| R2.8 | 室内信号差（地下室）| 高 | 中 | M5 阶段做 WiFi↔4G failover |
