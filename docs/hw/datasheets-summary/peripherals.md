## 1. ST7123 触摸控制器（新增）

| 项 | 规格 | 来源 |
|---|---|---|
| **类型** | I2C 电容触摸控制器 | Espressif `esp_lcd_touch_st7123` 组件 |
| **I2C 地址** | **0x55**（Espressif 默认）| `ESP_LCD_TOUCH_IO_I2C_ST7123_ADDRESS` |
| **屏幕分辨率** | 480 × 800 | p4c5_display.cc L222-223 |
| **I2C 总线** | SDA=GPIO7, SCL=GPIO8, 400kHz | ksdiy_lvgl_port.c L49-51 |
| **INT 引脚** | GPIO23（低电平有效）| ksdiy_lvgl_port.c L47 |
| **RST 引脚** | GPIO_NUM_NC（轮询模式，无硬件复位）| ksdiy_lvgl_port.c L45 |
| **初始化** | `esp_lcd_touch_new_i2c_st7123()` | ksdiy_lvgl_port.c L378 |

### ⚠️ I2C 地址勘误

| 位置 | 内容 | 状态 |
|---|---|---|
| `p4c5_board.cc` L11 注释 | `ST7123(0x5A)` | ❌ **错误**，应改为 `0x55` |
| `p4c5_display.cc` L217 代码 | `ESP_LCD_TOUCH_IO_I2C_ST7123_ADDRESS` /* 0x55 */ | ✅ 正确 |
| Espressif 驱动默认 | 0x55 | ✅ 正确 |

**影响**：仅注释错误，代码逻辑使用宏定义 `ESP_LCD_TOUCH_IO_I2C_ST7123_ADDRESS` = 0x55，功能不受影响。建议 CCA 在下次 commit 中修正注释。

### 与 ST7102 LCD 的关系

- **ST7102**：MIPI-DSI LCD 面板驱动（显示），走 DSI 总线，不走 I2C
- **ST7123**：I2C 触摸控制器，独立于 LCD 驱动
- 两者配套使用：ST7102 负责显示输出，ST7123 负责触摸输入

## 2. LSM6DS3TR-C（IMU - 6 轴姿态传感器）

| 项 | 规格 | 来源 |
|---|---|---|
| **类型** | 3D 加速计 + 3D 陀螺仪（6 轴 IMU）| 规格书 |
| **I2C 地址** | **0x6A**（默认）/ 0x6B（备用）| 规格书 |
| **加速度量程** | ±2/±4/±8/±16 g（可配）| 规格书 |
| **陀螺仪量程** | ±125/±245/±500/±1000/±2000 dps | 规格书 |
| **数据输出率** | 1.6 Hz - 6.6 kHz | 规格书 |
| **工作电压** | 1.71V - 3.6V（共用 ALDO3 = 3.3V）| 规格书 |
| **工作电流** | 0.55 mA（正常模式）| 规格书 |
| **封装** | 2.5×3.0×0.83 mm LGA-14 | 规格书 |
| **中断** | INT1/INT2（**原理图未连接**）| 原理图 |

⚠️ **芯片版本差异**：原理图丝印 LSM6DS3TR-C，规格书为 LSM6DSLTR。M1 需实机读 WHO_AM_I (0x0F) 确认型号。

### 关键寄存器

| 寄存器 | 地址 | 用途 |
|---|---|---|
| WHO_AM_I | 0x0F | 设备 ID（应返回 0x6A）|
| CTRL1_XL | 0x10 | 加速度计控制 |
| CTRL2_G | 0x11 | 陀螺仪控制 |
| CTRL3_C | 0x12 | 通用控制（复位+BDU+自动递增）|
