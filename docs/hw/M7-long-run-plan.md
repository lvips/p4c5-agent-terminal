## 1. 测试目标

### 1.1 核心目标

验证 p4c5-agent-terminal 固件在 **24 小时持续运行** 下的稳定性：

- 主循环无崩溃（0 次 panic / Guru Meditation / assert 失败）
- 所有子系统持续工作（PMIC + Display + Audio + 可选 4G）
- 无内存泄漏（heap 波动 < 5%）
- 无看门狗超时重启
- 电池充放电曲线符合预期

### 1.2 测试范围

| 子系统 | 是否参与 | 说明 |
|---|---|---|
| PMIC (AXP2101) | ✅ 必测 | 全程监控电压/温度/电量 |
| Display (ST7102) | ✅ 必测 | 持续显示 LVGL UI |
| Audio (ES8311+ES7210) | ✅ 必测 | 交替录放 + 双工 |
| 4G (ML307C) | ⊘ 可选 | 如 M7 已启用则加入 |
| IMU (LSM6DS3) | ⊘ 可选 | 如已集成则加入 |

### 3.2 自动监控脚本

建议在 `app_main.c` 主循环中添加以下自动监控：

```c
// 每 60 秒自动打印关键指标
static int64_t last_monitor_time = 0;
int64_t now = esp_timer_get_time();
if (now - last_monitor_time >= 60 * 1000000) {  // 60s
    last_monitor_time = now;

    // 内存监控
    size_t free_heap = heap_caps_get_free_size(MALLOC_CAP_DEFAULT);
    size_t free_internal = heap_caps_get_free_size(MALLOC_CAP_INTERNAL);
    ESP_LOGI(TAG, "[MONITOR] free_heap=%u, free_internal=%u",
             free_heap, free_internal);

    // PMIC 状态
    int battery_pct = p4c5_pmic_get_battery_level();
    int vbat_mv = p4c5_pmic_get_vbat_mv();
    bool charging = p4c5_pmic_is_charging();
    ESP_LOGI(TAG, "[MONITOR] battery=%d%%, vbat=%dmV, charging=%d",
             battery_pct, vbat_mv, charging);

    // 芯片温度
    int die_temp = p4c5_pmic_get_die_temp();
    ESP_LOGI(TAG, "[MONITOR] die_temp=%dC", die_temp);

    // Audio 错误计数（如有）
    // ESP_LOGI(TAG, "[MONITOR] i2s_err_count=%u", i2s_err_count);

    // 运行时间
    static uint32_t uptime_seconds = 0;
    uptime_seconds += 60;
    ESP_LOGI(TAG, "[MONITOR] uptime=%uh%um",
             uptime_seconds / 3600, (uptime_seconds % 3600) / 60);
}
```

## 4. 异常处理预案

### 4.1 异常检测与处理

| 现象 | 检测方式 | 可能原因 | 处理 |
|---|---|---|---|
| **主循环 hang** | heartbeat 停止 > 60s | 死锁 / 无限循环 | TWDT 30s 超时自动重启 |
| **Audio codec hang** | `esp_codec_dev_write` 超时 > 5s | I2S DMA 卡死 | 重新初始化 codec |
| **PMIC 通信失败** | I2C 读回超时 > 3 次 | I2C 总线干扰 | 重试 → 重启 I2C 总线 |
| **Display 白屏** | LVGL 帧率 = 0 > 10s | MIPI-DSI 异常 | 复位 display → watchdog |
| **内存耗尽** | `free_heap < 50KB` | 内存泄漏 | 日志记录 → 继续运行 |
| **温度过高** | `die_temp > 80°C` | 散热不足 / 短路 | 降频 → 日志告警 |
| **充电异常** | `vbat > 4.3V` 或 `vbat < 3.0V` | PMIC 故障 | 立即停止充电 |

### 4.2 自动恢复机制

```
┌─────────────┐     ┌──────────────┐     ┌──────────────┐
│  异常检测    │────→│  分类处理     │────→│  恢复/告警    │
├─────────────┤     ├──────────────┤     ├──────────────┤
│ heartbeat   │     │ 可恢复：      │     │ - codec 重启  │
│ 超时        │     │  - codec hang │     │ - I2C 复位    │
│             │     │  - I2C 故障   │     │ - display 复位│
│ 内存低      │     │  - display 异常│     │              │
│             │     ├──────────────┤     ├──────────────┤
│ 温度过高    │     │ 不可恢复：    │     │ - TWDT 重启   │
│             │     │  - 主循环 hang│     │ - 日志记录    │
│ 电压异常    │     │  - panic      │     │ - 通知 DSH    │
└─────────────┘     └──────────────┘     └──────────────┘
```

### 4.3 人工干预触发条件

以下情况需**人工介入**（暂停测试）：

1. **连续重启 > 3 次**：可能存在系统性 bug
2. **PA 温度 > 70°C**：可能散热问题
3. **ALDO4 电压 < 2.5V**：PMIC 可能故障
4. **电池电压 < 3.0V**：电池可能损坏
5. **串口日志出现 `Guru Meditation Error`**：需分析 panic 原因

## 5. 失败判定标准

### 5.1 24h 测试通过标准

| 指标 | 通过标准 | 说明 |
|---|---|---|
| 重启次数 | **= 0** | 任何重启视为失败 |
| Watchdog 触发 | **= 0** | TWDT 未触发 |
| Panic 次数 | **= 0** | 无 Guru Meditation |
| 内存泄漏 | **< 5%** | 24h 前后 heap 对比 |
| Audio 错误 | **= 0** | DMA underrun = 0 |
| Display 异常 | **= 0** | 无花屏/白屏 |
| 电池变化 | **符合预期** | 充电时递增，放电时递减 |
| PA 温度 | **< 70°C** | 手触烫但可坚持 3s |
| PMIC 温度 | **< 80°C** | 芯片温度安全范围内 |

### 5.2 24h 测试失败标准

**任何一项** 触发即判定失败：

1. ✅ 重启次数 > 0
2. ✅ Watchdog 触发 > 0
3. ✅ Panic / Guru Meditation > 0
4. ✅ 内存泄漏 ≥ 5%
5. ✅ 任何子系统不可恢复（需人工干预）
6. ✅ PA 温度 ≥ 70°C
7. ✅ 电池电压异常（< 3.0V 或 > 4.3V）

### 5.3 测试结果分类

| 结果 | 判定 | 后续 |
|---|---|---|
| **全部通过** | ✅ 24h 长稳 OK | 进入 M8 集成测试 |
| **内存泄漏 5-10%** | ⚠️ 可接受但需修复 | M8 修复后重测 |
| **单次重启** | ⚠️ 需分析原因 | 修复后重测 24h |
| **多次重启 / panic** | ❌ 失败 | 回退 M5/M6 排查 |
| **温度过高** | ❌ 硬件问题 | 检查散热 / PA 配置 |

## 8. 风险标注

| 风险 | 描述 | 缓解措施 |
|---|---|---|
| R-LR-1 | 长时间运行可能暴露内存泄漏 | 每小时记录 heap，5% 阈值告警 |
| R-LR-2 | PA 持续播放可能过热 | 每 6h 测温，70°C 暂停 |
| R-LR-3 | USB 供电不稳定导致电压跌落 | 确保 5V/2A 电源，万用表监控 |
| R-LR-4 | 串口日志文件过大 | 定期清理或限制文件大小 |
| R-LR-5 | 电池长时间充电可能膨胀 | 充满后停止充电或断开电池 |
